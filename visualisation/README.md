# BRFN Interactive Strategic Process Explorer

An educational interactive visualisation for the
Bristol Regional Food Network (BRFN) DESD Sprint 1 review.

## Run

Open `index.html` in any modern browser, or open this
folder in VS Code and use the Live Server extension.

No dependencies, installation, or internet connection required.

## Features

- Seven interactive enterprise business processes
- Play, Pause, Previous, Next and Reset controls
- Animated conceptual information flows
- Illustrative business data and activity logs
- Explanatory text for each stage
- Keyboard navigation with left/right arrows

## Relationship to Camunda

The formal strategic BPMN model remains in:

`../bpmn/strategic/BRFN-Strategic-BPMN-Sprint1.bpmn`

This visualisation explains the intended processes at a
conceptual level. It is not connected to Camunda, an
execution engine, a database, or a payment provider.

All example producers, customers, records and outcomes are
fictional demonstration data.

## Scope

The seven processes reflect the major business functions
represented in the BRFN strategic BPMN draft. Their
sequence and detailed behaviour remain subject to group
and tutor review.
